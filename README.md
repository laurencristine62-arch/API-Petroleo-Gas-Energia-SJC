# CINETEC

## Sobre o projeto
O Cinetec é um projeto acadêmico que analisa o setor de Petróleo, Gás e Energia em São José dos Campos – SP.

## Objetivo
Desenvolver um dashboard interativo no Power BI para apresentar informações sobre as instalações do setor, os empregos formais, o perfil dos trabalhadores e a participação desse setor no mercado de trabalho local.

## Ferramentas utilizadas
- Excel: organização e tratamento dos dados.
- Power BI: criação do dashboard.
- GitHub: documentação e acompanhamento do projeto.

## Sprints
- Sprint 1: planejamento do projeto, levantamento das necessidades do cliente e organização do backlog.
- Sprint 2: atualização e análise dos dados, desenvolvimento e validação do dashboard.

## Entregas
O repositório reúne a documentação das sprints, o backlog, as fontes de dados e os arquivos relacionados ao dashboard.

## Equipe
Projeto acadêmico desenvolvido em grupo.

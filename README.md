# API-Petroleo-Gas-Energia-SJC
Projeto de análise de dados do setor de Petróleo, Gás e Energia em São José dos Campos.
# Cinetec

## Sobre o projeto
Este projeto acadêmico tem como objetivo analisar dados do setor de Petróleo, Gás e Energia no município de São José dos Campos – SP, utilizando dados abertos e visualizações no Power BI.

## Objetivo
Organizar e analisar informações sobre as atividades econômicas, os empregos formais e o perfil dos trabalhadores do setor.

## Perguntas do projeto
1. Quais são as principais instalações do setor de Petróleo, Gás e Energia em São José dos Campos?
2. Quantos empregos formais o setor gera no município?
3. Qual é o perfil dos trabalhadores do setor?
4. Qual é a participação do setor no mercado de trabalho local?

## Ferramentas utilizadas
- GitHub para documentação e organização do projeto.
- Excel para organização e tratamento dos dados.
- Power BI para construção do dashboard.

## Desenvolvimento por sprints
- Sprint 1: definição do problema, levantamento das fontes e organização inicial do backlog.
- Sprint 2: tratamento e conferência dos dados, organização das informações e desenvolvimento do dashboard.

## Equipe
Projeto desenvolvido em grupo como atividade acadêmica.

## Observação
Os números e indicadores apresentados deverão ser conferidos com as bases originais e suas fontes antes da publicação dos resultados finais.

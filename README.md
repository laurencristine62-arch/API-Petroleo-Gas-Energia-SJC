# CINETEC

# API – Petróleo, Gás e Energia em São José dos Campos

## Sobre o projeto
Este projeto acadêmico tem como objetivo analisar o setor de Petróleo, Gás e Energia no município de São José dos Campos – SP, utilizando dados abertos para compreender melhor o mercado de trabalho e as atividades econômicas relacionadas ao setor.

## Objetivo
Desenvolver um dashboard interativo no Power BI para apresentar informações importantes sobre o setor, auxiliando na análise e compreensão dos dados.

## Perguntas que o projeto busca responder
- Quais são as principais instalações do setor de Petróleo, Gás e Energia em São José dos Campos?
- Quantos empregos formais o setor gera no município?
- Qual é o perfil dos trabalhadores desse setor?
- Qual é a participação do setor no mercado de trabalho local?

## Ferramentas utilizadas
- Excel: organização e tratamento dos dados.
- Power BI: criação do dashboard interativo.
- GitHub: armazenamento dos arquivos e documentação do projeto.

## Desenvolvimento por Sprints

### Sprint 1 – Planejamento
Definição do tema, identificação das necessidades do cliente, elaboração das perguntas e organização do backlog.

### Sprint 2 – Tratamento e análise dos dados
Levantamento e organização das bases de dados, análise das informações, desenvolvimento dos indicadores e criação do dashboard no Power BI.

## Entregas
O repositório contém o backlog do produto, as documentações das Sprints, as fontes de dados utilizadas e o arquivo do dashboard desenvolvido no Power BI.

## Equipe
Projeto acadêmico desenvolvido em grupo na FATEC.

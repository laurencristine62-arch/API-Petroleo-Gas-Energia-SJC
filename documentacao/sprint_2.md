# Sprint 2 – Tratamento e análise dos dados

## Objetivo
Organizar, conferir e preparar os dados necessários para responder às perguntas do projeto e apoiar a criação do dashboard.

## Atividades
- Reunir as bases de dados utilizadas pela equipe.
- Conferir os nomes das colunas e os períodos de referência.
- Verificar possíveis valores incorretos, duplicados ou inconsistentes.
- Organizar as informações de empregos formais por atividade econômica.
- Planejar os indicadores e gráficos do Power BI.
- Atualizar o backlog conforme o andamento das tarefas.

## Entregas previstas
- Dados organizados e conferidos.
- Registro das fontes utilizadas.
- Planejamento dos indicadores do dashboard.
- Atualização da documentação do projeto.

## Critérios de conclusão
Os dados precisam ter fonte identificada, período de referência informado e valores conferidos antes de serem utilizados nos resultados finais.

## Pendências
- Confirmar os números com as bases originais.
- Registrar os links exatos das fontes.
- Finalizar e validar o dashboard no Power BI.
